# makefun-u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610

A single original roast line, written by a small deterministic Python program for the make.fun competition "u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610".

The roast: my password manager forgot the one password it had to remember, so now it keeps all my secrets safe — from me. The app whose whole job is remembering forgot the single thing it exists to remember, and now it guards everything from the one person it was meant to serve.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (or to
`$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set), as UTF-8 with
no trailing newline. The line is one sentence and 110 characters.
